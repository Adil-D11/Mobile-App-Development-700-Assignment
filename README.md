Smart Pantry Manager

App Description

Smart Pantry Manager is an Android application developed using Java and XML in Android Studio. The app aims to help users reduce food wastage by managing the ingredients they already have at home and suggesting recipes they can prepare using those ingredients.
Users can register and log in, manage their pantry ingredients, generate recipes based on available ingredients, view their previously generated recipes, and access help and settings.
The application is designed to make meal planning easier, encourage users to use ingredients before they go to waste, and reduce the need to purchase additional ingredients for suggested recipes.

Database Choice

The application uses SQLite as its database.
SQLite was chosen because it is lightweight, stores data locally on the device, and does not require a separate database server or an internet connection for local database operations. It also supports relational tables and CRUD operations (Create, Read, Update, and Delete), which are needed to manage user accounts, pantry ingredients, and recipe history.
SQLite was also suitable because it had been covered in our coursework, allowing us to apply our existing database knowledge during development.

 Setup and Run Instructions

1. Download or clone this repository to your computer
2. Install Android Studio if it is not already installed
3. Open Android Studio and select Open
4. Navigate to the downloaded project folder and select it
5. Allow Android Studio to sync the Gradle files and download any required dependencies
6. If prompted, install the required Android SDK components
7. Connect an Android device with USB debugging enabled, or create and start emulator
8. Select the device or emulator in Android Studio
9. Click the Run button to build and launch the application

The SQLite database is managed by the application. Users can register an account and begin using the app after launching it

 Main Features

- User registration and login
- Pantry ingredient management
- Recipe generation based on available ingredients
- Previous recipe history
- Help page explaining the application
- Settings for account management and preferences
